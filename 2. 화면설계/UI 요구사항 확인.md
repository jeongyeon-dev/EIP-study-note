UI 관련해서,  
CLI: 텍스트 기반 인터페이스, 그 검은색 터미널 같은  
GUI: 그래픽 기반, 마우스와 화면 창 같이 현재 컴퓨터에서 통상적으로 사용하는 것  
NUI: 사용자 반응 기반?.. 추상적이긴 한데, 터치 · 음성 기반으로 요즘 신세대 포스기 같은 것  
OUI: 유기적 상호 작용?.. 디스플레이 없이 내 팔에 광선 쏳아 GUI 그려진 예시 같은 거 생각하기  
이런 식으로 차세대로 넘아간다.

UI 화면 설계를 하려면?  
Figma 같은 도구를 활용해 일종의 설계도를 그려야 한다.  
큰 틀로 "스토리 보드"라고 한다. 이 안에 정책?같은 각종 정보를 다 담고 있고, 그들 중  
"와이어 프레임"이 있는데, 이는 *화면 단위의 레이아웃*으로, 실제로 화면 예시가 그려져 있는 부분.  
이걸 <u>실물화</u>할 필요가 있는데, 말 그대로 화면만 그려지는 것을 "목업"이라고 하며,  
여기에 버튼 등이 클릭해서 이동이 가능한 것을 "프로토타입"이라고 한다.
