운영체제에 대한 내용을 다루는 섹션이다.  
말이 운영체제이지, 기출문제를 보아서 요구하는 사항이 내용에 비해 국소적이라고 판단됨.  

외우는 데에도 패턴이 있다.  
운영체제의 특성으로: 인터페이스, 스케줄링, 자원관리.. 추후 소단원에서 설명  
운영체제 종류: Window, Unix(Linux(Android), Mac)  

CLI(Command Line Interface)  
GUI(Graphic User Interface)  

Unix 계열 접근 권한 설정 명령어:  
chmod User(4.2.1) Group(4.2.1) Others(4.2.1) 파일명  
괄호 안에는 Read.Write.Execute로 합을 더하면 된다.   
<br>

기출문제가 일괄적이라 일단 분석부터 한다.
운영체제 => 어떤 운영체제? 문제 × 2
명령어 => chmod 문제 × 2  
프로세스 스캐줄링 => 계산식 같은 <u>정의형</u> 문제 × 1, 유형별 같은 <u>기본형</u>문제 × 1  
프로세스 스캐줄링 알고리즘 => 도식/식을 보고 횟수 시간 등 <u>연산형</u> 문제 × 3  
프로세스 기본 => 상태 전이도 같은 <u>기본형</u>문제 × 1
